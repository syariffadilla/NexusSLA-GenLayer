# NexusSLA Web Dashboard

The user-facing application layer for the NexusSLA Intelligent Contract deployed on GenLayer.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom Dark Web3 Design Tokens
- **Icons**: Lucide React
- **Contract Integration**: GenLayer JSON-RPC / `contract.ts`

## Getting Started
```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## Features
- Branded orbital loading splash screen
- Full protocol dashboard with uptime visualization
- Active SLA management with collateral deposit/withdrawal modals
- Claim filing with real-time domain whitelist validation and animated AI Adjudication Pipeline
- Dispute claim console with counter-evidence verification
- Court case detail featuring AI consensus visualizer, deterministic penalty engine stack, and claim lifecycle timeline
- Contract explorer inspecting raw on-chain state
